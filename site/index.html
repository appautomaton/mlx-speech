From an idea to a waveform

A few lines.
Then press play.

Install the library, choose a model, and make something you can hear.

  1. 01
    Bring your Mac.

    Apple Silicon (M1 or later), Python 3.13+, and enough memory for your chosen model.

  2. 02
    Install mlx-speech.pip install mlx-speech
  3. 03
    Run your first example.

    Weights download on first use. Later, pass a local checkpoint path to work offline.

Using FireRedTTS3 Base? It currently needs the GitHub source installation.

YOUR FIRST SESSIONPYTHON

Text to speech

import mlx_speech
from mlx_speech.audio import write_wav

# Pick a voice model.
model = mlx_speech.tts.load("fish-s2-pro")

# Make something you can hear.
result = model.generate(
    "A little less cloud. A little more you."
)

write_wav(
    "hello.wav", result.waveform,
    sample_rate=result.sample_rate,
)
Output file hello.wavWAV

Voice cloning

import mlx_speech
from mlx_speech.audio import write_wav

model = mlx_speech.tts.load("fish-s2-pro")

# Supply a recording you have permission to use.
result = model.generate(
    "This is what local sounds like.",
    reference_audio="reference.wav",
    reference_text="Words spoken in the recording.",
)

write_wav(
    "cloned.wav", result.waveform,
    sample_rate=result.sample_rate,
)
Output file cloned.wavWAV

Speech to text

import mlx_speech

# Choose a speech-recognition model.
model = mlx_speech.asr.load("qwen3-asr-1.7b")

# Use an existing audio recording.
result = model.generate("recording.wav")
print(result.text)
